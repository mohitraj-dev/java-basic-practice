# Java Basics

A structured collection of Java fundamentals, coding examples, and programming exercises.

## Objective

To build a strong foundation in Java programming and prepare for Java Full Stack Development and technical interviews.

## Topics Covered

* Java Fundamentals
* Variables and Data Types
* Operators
* User Input
* Conditional Statements
* Loops
* Pattern Programming
* Arrays
* Strings
* Methods
* Object-Oriented Programming (OOP)
* Constructors
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction
* Exception Handling
* Collections Framework
* Programming Practice

## Technologies

* Java
* Git
* GitHub

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository.
3. Open the project in your preferred Java IDE.
4. Navigate to the program you want to run.
5. Compile and execute the Java file.

## Learning Approach

* Practise concepts with small programs.
* Solve problems independently.
* Write readable and maintainable code.
* Revise previous topics regularly.
* Commit meaningful changes to GitHub.

## Goal

Develop strong Java fundamentals and progress towards advanced Java, Spring Boot, REST APIs, and full-stack application development.

**Learning by coding, one concept at a time.**
